## 二、关键函数详细说明

### 2.1 主函数相关

#### `main()` [cli/main.go:21-23]
**用途**: 程序入口函数
**说明**: 简单调用 `cli.Start()` 启动 CLI 框架

#### `cli.Start()` [cli/main.go:21-23]
**用途**: 启动命令行界面
**说明**: 调用 `cmd.Execute()` 开始 Cobra 框架的命令处理

### 2.2 Cobra 命令框架相关

#### `cmd.Execute()` [cli/cmd/root.go:145-156]
**用途**: Cobra 框架执行入口
**说明**:
- 设置自定义的 UsageFunc
- 设置帮助模板
- 禁用默认命令自动补全
- 设置版本信息
- 调用 rootCmd.Execute() 解析命令行参数

#### `init()` [cli/cmd/root.go:158-176]
**用途**: 全局变量和参数初始化
**说明**: 在包加载时自动执行，注册全局命令行参数：
- `--debug` (-d) - 启用调试日志
- `--btf` (-b) - BTF 模式（0：自动，1：core，2：non-core）
- `--hex` - 以十六进制格式打印字节字符串
- `--mapsize` - 每个 CPU 的 eBPF map 大小（KB）
- `--pid` (-p) - 目标特定 PID
- `--uid` (-u) - 目标特定 UID
- `--logaddr` (-l) - 日志器地址（file/tcp/ws）
- `--eventaddr` - 事件收集器地址
- `--ecaptureq` - eCaptureQ 监听服务器
- `--listen` - HTTP 配置更新服务器端口
- `--tsize` (-t) - 文本模式下的截断大小
- `--eventroratesize` - 事件收集器文件轮转大小
- `--eventroratetime` - 事件收集器文件轮转时间

### 2.3 环境检测相关

#### `detectEnv()` [cli/cmd/env_detection.go]
**用途**: 综合环境检测
**说明**: 依次调用 `detectKernel()` 和 `detectBpfCap()`

#### `detectKernel()` [cli/cmd/env_detection.go]
**用途**: 检测内核版本是否符合要求
**说明**:
- 获取当前内核版本
- x86_64 架构要求内核 >= 4.18
- arm64 架构要求内核 >= 5.5
- 不符合则返回错误

#### `detectBpfCap()` [cli/cmd/env_detection.go]
**用途**: 检测 BPF 权限
**说明**:
- 检查进程是否有 CAP_BPF 权限
- 或者是否有 CAP_SYS_ADMIN 权限
- 没有权限则返回错误

### 2.4 TLS/OpenSSL 命令相关

#### `openSSLCommandFunc()` [cli/cmd/tls.go]
**用途**: TLS 命令执行函数
**说明**:
- 处理 pcapfilter 参数
- 调用 `runProbe(factory.ProbeTypeOpenSSL, oc)` 启动探针

### 2.5 探针工厂机制

#### `factory.RegisterProbe()` [internal/factory/probe_factory.go:107-109]
**用途**: 注册探针构造函数
**说明**: 将探针构造函数注册到 `globalFactory` 中

#### `factory.CreateProbe()` [internal/factory/probe_factory.go:112-114]
**用途**: 创建探针实例
**说明**: 从 `globalFactory` 中查找并返回指定类型的探针实例

### 2.6 主控制逻辑

#### `runProbe()` [cli/cmd/root.go:248-402]
**用途**: 探针运行主控制函数
**说明**: 核心流程控制函数，负责：
1. 初始化日志输出器 `initLogger()`
2. 初始化 ecaptureQ 服务器（如果启用）
3. 打印程序信息
4. 启动 HTTP 配置服务器
5. 启动版本检查协程
6. 执行配置检查 `probeConfig.Validate()`
7. 获取探针构造函数 `factory.CreateProbe()`
8. 创建探针实例
9. 调用探针初始化 `probe.Initialize()`
10. 调用探针启动 `probe.Start()`
11. 进入信号等待循环
12. 退出时调用 `probe.Stop()` 和 `probe.Close()`

#### `initLogger()` [cli/cmd/root.go:179-245]
**用途**: 初始化日志输出器
**说明**:
- 创建基础 zerolog.Logger
- 根据地址类型创建不同的 writer:
  - tcp://: TCP 连接
  - ws:// / wss://: WebSocket 连接
  - 文件路径: 文件输出（支持轮转）
- 组合多个输出源

### 2.7 配置校验相关

#### `Configuration.Validate()` [internal/domain/configuration.go:18-20]
**用途**: 配置校验接口
**说明**: 各探针配置实现此接口进行特定校验

### 2.8 探针初始化相关

#### `BaseProbe.Initialize()` [internal/probe/base/base_probe.go:70-123]
**用途**: 探针基类初始化
**说明**:
1. 配置校验
2. 初始化上下文、日志
3. 创建事件分发器 `events.NewDispatcher()`
4. 创建输出写入器工厂 `writers.NewWriterFactory()`
5. 创建文本输出处理器 `handlers.NewTextHandler()`
6. 注册处理器到分发器

#### `OpenSSLProbe.Initialize()` [internal/probe/openssl/openssl_probe.go:71-98]
**用途**: OpenSSL 探针特定初始化
**说明**:
1. 调用父类 `BaseProbe.Initialize()`
2. 类型断言配置为 `*Config`
3. 验证 SSL 版本是否支持
4. 记录初始化日志

### 2.9 探针启动相关

#### `BaseProbe.Start()` [internal/probe/base/base_probe.go:127-135]
**用途**: 探针基类启动
**说明**:
1. 检查是否已在运行
2. 设置 `isRunning` 标志

#### `OpenSSLProbe.Start()` [internal/probe/openssl/openssl_probe.go:101-159]
**用途**: OpenSSL 探针启动逻辑
**说明**:
1. 调用父类 `BaseProbe.Start()`
2. 确定 eBPF 字节码文件名
3. 从 assets 加载 eBPF 字节码
4. `setupManager()` 设置 eBPF manager
   - 根据模式调用 `setupManagerText/Keylog/PcapNG()`
   - 配置 uprobe/kprobe/tc 挂载点
   - 设置 `mapNameToDecoder` 映射
5. 初始化 eBPF manager
   - `bpfManager.InitWithOptions()`
6. 启动 eBPF manager
   - `bpfManager.Start()` 挂载到内核
7. `retrieveEventMaps()` 获取 eBPF maps
   - 创建 `eventFuncMaps`: `*ebpf.Map` -> decoder
8. 启动事件读取器
   - `StartPerfEventReader()` 为每个 map

#### `OpenSSLProbe.Stop()` [internal/probe/openssl/openssl_probe.go:191-194]
**用途**: OpenSSL 探针停止
**说明**: 调用父类 `BaseProbe.Stop()`

#### `OpenSSLProbe.Close()` [internal/probe/openssl/openssl_probe.go:205-225]
**用途**: OpenSSL 探针关闭
**说明**:
1. 停止 eBPF manager
2. 调用父类 `BaseProbe.Close()`

### 2.10 事件处理相关

#### `BaseProbe.StartPerfEventReader()` [internal/probe/base/base_probe.go:242-264]
**用途**: 初始化 perf 事件读取器

## 五、关键流程说明

### 5.1 探针注册流程
1. 各探针的 `init()` 函数在包加载时执行
2. 调用 `factory.RegisterProbe()` 将构造函数注册到 `globalFactory`
3. 运行时通过 `factory.CreateProbe()` 获取构造函数
4. 调用构造函数创建探针实例

### 5.2 eBPF 程序加载流程
1. `OpenSSLProbe.Start()` 确定字节码文件名
2. 从 assets 加载编译好的 .o 文件
3. `setupManager()` 设置 eBPF manager
   - 配置 uprobe/tc 挂载点
   - 设置常量编辑器 (target_pid, target_uid, less52)
4. 调用 `bpfManager.InitWithOptions()` 初始化
5. 调用 `bpfManager.Start()` 挂载到内核
6. `retrieveEventMaps()` 获取 eBPF maps 并关联解码器
7. 为每个 map 启动 perf event reader

### 5.3 事件处理流程
1. eBPF 在内核中捕获事件
2. 事件写入 eBPF map（perf/ringbuf）
3. 用户态 reader 读取事件
4. 调用 `decoder.Decode()` 解码为事件结构
5. 调用 `dispatcher.Dispatch()` 分发事件
6. 各 Handler 处理并输出

### 5.4 配置重载流程
1. HTTP API 接收新配置
2. 验证配置有效性
3. 发送到 `reRloadConfig` 通道
4. 主循环接收新配置
5. 设置 `isReload = true`
6. 调用 `probe.Stop()` 停止旧探针
7. 调用 `probe.Close()` 关闭旧探针
8. 调用 `probe.Initialize()` 初始化新配置
9. 调用 `probe.Start()` 启动新探针

- 环境检测失败：程序退出

## 七、新架构特点

### 7.1 领域驱动设计 (DDD)
- `internal/domain/`: 纯接口定义，无外部依赖
- 清晰的接口分离，便于测试和扩展

### 7.2 工厂模式
- `internal/factory/`: 探针创建工厂
- 支持动态注册和发现

### 7.3 分层架构
- 输出层分离为 encoders 和 writers
- Handler 模式处理不同输出格式
- 灵活的组合和扩展

### 7.4 错误处理
- `internal/errors/`: 统一的错误定义
- 错误码和包装支持

## 八、注意事项

1. **权限要求**: 需要 root 权限或 CAP_BPF/CAP_SYS_ADMIN 能力
2. **内核版本**: 不同架构有最低内核版本要求
3. **BTF 支持**: 推荐使用 CO-RE 模式（BTF）
4. **容器环境**: 在容器中运行需要特殊处理 BTF
5. **信号处理**: 支持 SIGINT 和 SIGTERM 优雅退出
6. **配置重载**: 支持通过 HTTP API 动态重载配置
